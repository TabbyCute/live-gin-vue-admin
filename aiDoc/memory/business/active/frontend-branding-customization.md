# 管理后台品牌配置化

## 基本信息

- 提出日期：2026-09-19
- 当前状态：`blocked`
- 需求类型：前端品牌 / 配置
- 优先级：中
- 需求文件：`aiDoc/memory/business/active/frontend-branding-customization.md`

## 用户原始意图摘要

将管理后台的项目名称、Logo、水印和页脚品牌内容改为自有项目品牌，并将项目名称等品牌字段放入 YAML 配置。

## 影响范围

- 后端：增加品牌配置结构与公开读取接口
- 前端：页面标题、Logo、登录页、布局和关于页面读取统一品牌配置
- 配置：`server/config.dev.yaml` 与 `server/config.prod.yaml` 保持同结构
- 合规：必须保留仓库规则和许可证要求的版权、作者署名及授权提示

## 当前阻塞

- 用户要求删除现有作者署名、版权、Powered by 和授权提示。
- `AGENT.MD` 与 `aiDoc/relations/licensing-and-branding.md` 明确禁止在缺少仓库内可审计授权依据时删除、隐藏或弱化这些内容。
- 当前仓库中未发现支持移除相关声明的商用授权文件或版权所有者许可。

## 可执行的合规方案

- 保留原项目许可证和归属声明。
- 新增 YAML 品牌配置，用于自有项目名称、Logo、浏览器标题和业务水印。
- 在页面上区分“当前产品品牌”和“底层开源项目归属”。

## 恢复条件

- 用户接受保留现有合规声明的配置化方案；或
- 仓库中加入可审计的授权文件，明确允许移除相关展示。
