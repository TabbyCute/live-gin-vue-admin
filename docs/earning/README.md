# 主播收益结算与提现审核

> 2026-11-03扩展：人工出款已支持frozen→paid、withdrawal_paid及提现paid/cancelled；此前“paid恒为0/出款未接入”的描述是阶段历史。当前行为以[人工出款前端契约](../payout/manual-frontend-integration.md)与[验证记录](../payout/manual-verification-20261103.md)为准。

2026-11-01：实现收益事实 → 结算申请/双人复核 → 独立可提现账户 → 提现申请与冻结 → 系统对账 → 人工审核。2026-11-02继续接入真实绑定账户和“提交打款中心”，创建唯一ready订单及只读列表/详情。审核通过状态仍为`approved`，金额继续冻结，没有派发或“手工标记付款成功”接口。

六个后台页面位于“直播管理”：直播收益、结算兑换规则、收益结算、主播可提现账户、提现审核、收益对账。配置兑换规则没有预设币种、比例或真实资金；创建人与复核人必须不同，角色 888 也不例外。

已接入真实礼物订单及钱包扣款/退款证明。大赏 `bounty`、赠送 `donation`、守护 `guard`、粉丝团 `fan_club`、充电 `charge` 使用统一收益事实接入边界；这些业务尚未实现，未经来源适配器核验不能结算。消费钱包与可提现账户分离，本模块不变更消费钱包内核。

提现申请默认开放且没有全局开关：符合本人主播、运营提现权限、低风险、余额和账务条件时可申请并原子冻结，当前流程不读取或判断用户实名认证、主播认证或收款方实名状态。提现申请必须选择本人有效payeeAccountNo，由数据库账户提供方在同一事务保存不可变脱敏快照；审核通过及创建待出款订单仍保持冻结，不会实际打款。未来真实派发必须重新核验既定收款账户版本、状态与风险，不能反向改变申请结果。本机测试结果不代表目标环境容量、HA、备份恢复或平台依赖安全问题已经验收。
