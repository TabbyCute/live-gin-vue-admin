# 直播间观众与在线状态服务

2026-11-06：后端、管理端和实际观看端 H5Player 已完成接入；远程正式数据库已完成增量迁移与资金摘要校验。**应用及前端尚未发布到远程运行环境**。本目录记录实现事实、复现方法和发布边界，不将本机测试结果当成生产容量承诺。

后台“直播间”与“直播场次”页面保留原有主播、房间及场次状态，并展示当前登录会员数、游客数；场次详情增加连接、峰值、累计、点赞、时长、检查点、Worker 和积压状态。普通无权限角色不展示统计，服务端仍独立校验当前权限。统计故障显示未知/降级，不用零值冒充实时数据。

本期没有 WebSocket、弹幕或消息推送。在线状态是心跳 TTL 下的近实时值；游客数是有效签名游客身份数，不是物理自然人数；多标签页可能具有独立游客身份。SRS 连接不等于登录用户在线。观看时长是服务端约束后的客户端播放状态估计，不能用来自动分钱、计费或作为不可抵赖的播放凭证。
