# 前台客户端产品概览

> 审计日期：2026-11-14。范围仅含用户/主播前台客户端；不包含 `web/` 运营管理后台。事实基线为独立源码 `/Users/tabby/Desktop/IM/H5Player`，主仓库 `server/assets/h5/` 是其构建产物。本文中的「待确认」表示源码无法证明，不得由设计平台自行补成既有功能。

## 1. 产品定位与范围

产品是面向游客、注册用户和主播的直播内容客户端，当前覆盖：注册登录、直播发现、直播观看、关注/收藏/拉黑/观看记录、主播公开主页、主播申请与开播、钱包只读、送礼、主播收益/提现与收款账户管理。

交付目标平台：

- H5：当前真实生产实现基线，移动宽度 `<=767px`。
- PC Web：与 H5 共用 Vue 应用，当前源码已有 `Platform` 宽屏分支；不是运营后台。
- Android / iOS：仓库内未发现原生工程、Capacitor/Cordova/uni-app 配置或系统权限声明。设计可以复用移动信息架构，但原生导航、推流、分享、相册权限、通知权限和上架规范均为「待确认」。

明确排除：`web/src/view/**` 管理后台、后台 RBAC 配置页、银行对账后台、公司出款后台、服务端运维工具。

## 2. 技术架构

| 层 | 当前实现 | UI/UX 影响 |
| --- | --- | --- |
| 应用 | Vue 3.5、Vite 8、JavaScript | 单页应用；页面按路由懒加载 |
| 路由 | Vue Router 5，History 模式 | 公开/登录/主播审核通过三类进入条件；刷新需服务端 history fallback |
| 状态 | Pinia 4 | 用户、社交、钱包、礼物、收益、系统主题分别隔离；账号切换清空敏感状态 |
| UI | Vant 4 + 自研组件 | 移动端优先；PC 使用同组件的宽屏布局 |
| 国际化 | Vue I18n，中/英语言包 | 只有基础/脚手架文案完成国际化，大量业务页仍为中文，完整多语言为待确认 |
| 主题 | CSS Variables，light/dark | 已有浅色/深色；跟随系统，用户可手动切换（当前生产入口不明显） |
| 播放 | HLS 自研封装、懒加载 HLS 内核 | 自动播放受浏览器限制；存在手动播放、静音授权、缓冲、失败恢复状态 |
| 实时 | HTTP presence；Realtime Adapter 预留 | 在线/点赞近实时；没有真实 IM/WebSocket 聊天投递，不能设计成已上线聊天 |
| 网络 | Fetch 封装、默认 15s 超时、Bearer JWT | 统一处理 401、超时、断网、业务码、Retry-After、X-Request-ID |
| 响应式 | `matchMedia(max-width:767px)` | H5 与 PC 同路由、同数据，布局独立适配 |

源码：`H5Player/package.json`、`src/routers/index.js`、`src/service/request.js`、`src/components/common/platform.vue`。

## 3. 用户角色与访问模型

| 角色/状态 | 可访问能力 | 限制 |
| --- | --- | --- |
| 游客 | 热门/新秀/广场直播列表、直播间观看、主播公开主页、榜单、公开页面 | 不能关注、收藏、点赞、送礼、看关注/历史、进入个人中心；游客 presence 可计在线 |
| 已登录普通用户 | 游客能力 + 个人中心、资料、钱包、送礼记录、社交、收藏、点赞、申请主播 | 钱包可能停用；账号受限时接口拒绝；无主播收益/开播入口 |
| 主播申请审核中 | 普通用户能力 + 查看申请进度 | 不能进入开播与主页管理 |
| 主播申请未通过 | 普通用户能力 + 查看原因、重新申请 | 重新提交前可编辑申请资料 |
| 审核通过主播 | 普通用户能力 + 开播台、主页管理、收益/提现 | 实际开播还要求主播状态正常、直播权限开启、风控/资格检查通过 |
| 受限主播 | 仍可查看身份/状态 | 停用、封禁、权限关闭或资格失败时禁止生成开播 Key；显示原因/截止时间 |

账号状态映射：正常、停用、封禁、注销；实名认证仅展示未认证/审核中/已认证/未通过/失效，不是提现的前置条件。客户端路由权限依据登录状态和 `applyStatus=2`，细粒度 roles/permissions 守卫已预留但当前路由未声明具体代码。

## 4. 核心业务模块

1. 身份与账号：手机号注册/短信码/密码登录、会话恢复、资料编辑、改密、退出。
2. 直播发现：关注、热门分类、新秀、广场、看过；公开房间列表和游标/页码分页。
3. 直播间：HLS 播放、游客/会员在线、关注、收藏、点赞、拉黑、礼物、音频授权。
4. 社交：关注、粉丝、互关、共同关注、黑名单、观看记录、公开资料。
5. 主播：申请审核、直播间配置、推流凭证、场次恢复/结束、直播历史。
6. 主播主页：公开资料、相册、贡献榜、守护列表/方案、分享；主播管理相册和介绍。
7. 钱包与礼物：COIN 余额/流水、礼物目录与赠送、结果恢复、订单与退款展示。
8. 收益与提现：收益汇总、结算记录、收款账户、提现申请/恢复、审核/付款终态。

## 5. 关键数据与安全原则

- 所有金额、数量、版本、分页总数按十进制字符串展示与计算，禁止用 JavaScript `Number` 处理大额资金；客户端使用 `BigInt`。
- APP JWT 仅放 `Authorization: Bearer`；不能与管理后台 `x-token` 混用。401 触发清会话并回登录；迟到的旧账号 401 不能注销新账号。
- 钱包、礼物、收益响应 `no-store`；收款完整资料只在绑定表单内存中存在，关闭即清除。
- 送礼、提现、相册写操作和开播准备都有幂等/版本恢复语义；「结果未知」不是确定失败，必须保留原参数/原请求键查询或重试。
- 公开业务只使用 `accountNo/anchorNo/roomNo/sessionNo/orderNo/withdrawalNo`，不展示数据库主键、钱包内部号、分成内部快照或完整银行资料。
