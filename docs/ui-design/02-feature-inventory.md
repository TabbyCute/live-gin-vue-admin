> `已实现` 指源码存在真实交互与接口；`部分` 指页面存在但数据或下游未接；`占位` 指仅演示/静态；`待确认` 指源码没有事实依据。

## 2. 数据与状态管理清单

| Store | 持有内容 | 清理/刷新规则 |
| --- | --- | --- |
| user | account、认证状态、主播身份、错误 | 退出/401 清理全部关联 Store；刷新单飞；网络验证失败保留未过期 token 但标 error |
| social | 计数、关系、收藏、观看会话 | 账号切换清空；列表批量状态；乐观更新后以服务端事实为准 |
| wallet | 余额、流水、游标、错误、冷却 | 账号绑定；不持久化；余额/流水可独立失败；503 冷却 |
| gift | 目录、选择分类、历史、待确认送礼 | 待确认最小字段按账号持久化；账号切换隔离；成功后重读钱包 |
| earning | 概览、提现列表、待确认提现、恢复状态 | 待确认四参数按账号持久化；列表/余额不缓存；可见时对进行中单轮询 |
| system | locale、theme、环境、初始化 | 主题跟随系统或手动持久化；语言更新标题 |

## 3. 未实现或不得虚构的功能

- 直播聊天发送、弹幕、私信、IM 在线消息。
- 客户端充值、退款申请、修改钱包、修改提现状态、实际银行付款。
- 礼物成功后的全房广播确认、客户端守护直购/开通确认。
- 真实榜单数据、榜单用户点击详情（当前页面无跳转）。
- 原生推送、相机/麦克风推流、系统通知、App 深链、系统支付。
- 收款账户编辑/删除/恢复、读取完整资料、认证成功标识。
- 多国家手机号注册；当前仅中国大陆手机号。
