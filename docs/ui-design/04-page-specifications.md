# 逐页 UI 设计要求

## 0. 全页通用要求

每张页面设计稿必须同时给出：默认、首屏加载、局部加载、空、失败/可重试、断网/超时、登录过期、按钮提交中/禁用、成功反馈。列表额外提供刷新、加载更多、已到底、筛选无结果；资金写操作额外提供「结果未知、保留原请求」而不是普通失败。

H5 画板建议 390×844，并补 320px 最小宽度与 430px 宽屏；PC 画板建议 1440×900，并补 1024px 收缩态。Android/iOS 只在交互差异处单独出稿，不能假设已有原生实现。

### C-P01 登录/注册

- 用途：建立独立 APP 会话，并在认证后返回原访问页。
- 布局：PC 左侧品牌图形、卖点与版权，右侧居中卡片；H5 移除左视觉，顶部品牌+完整表单，底部留安全区和键盘空间。
- 模式：登录 Tab（手机号、密码、记住手机号）；注册 Tab（手机号、短信码+发送按钮、昵称可选、密码、确认密码）。两种模式都必须勾选协议。
- 校验：仅中国大陆 11 位手机号；短信码 6 位数字；密码 8–72 字节；昵称≤64字符；确认密码一致。错误紧贴字段，不只用 Toast。
- 状态：`required/expired/missing/verifyFailed` 顶部通知；短信发送中/60s倒计时/失败；登录或注册并登录中；注册成功但自动登录失败；网络/超时/服务端错误。
- 操作：密码显隐；协议新窗口；登录/注册切换清空敏感字段；成功 `replace` 安全 redirect。
- 待确认：正式 Logo/品牌名；协议地址与内容；是否支持国际手机号、忘记密码、第三方登录。源码没有这些能力，不在主稿中擅自增加。
- 证据：`module_system/pages/login/index.vue`、`stores/store_user.js`、`utils_phone.js`。

### C-P02 直播发现首页

- 用途：发现直播和回访已关注/看过内容。
- 结构：主 Tab「关注/热门/新秀/广场/看过」；热门下二级分类「所有+顶级分类」；直播卡片包含封面、直播/看过标签、观看量、头像、昵称、标题；全局底部 Tab「首页/榜单/我的」。
- 交互：主/子分类切换重置分页；下拉刷新；滚动加载；公开卡进入直播间；看过卡进入账号资料；关注/看过未登录时提示并跳登录。
- 状态：分类与房间列表独立加载/失败；分类失败仍允许展示无分类列表；空文案随 Tab 变化；图片失败显示渐变占位；加载更多失败保留已加载项。
- 事实限制：新秀/广场当前未向 API 传独立筛选条件，视觉可保留入口但必须在产品批注中标「排序/筛选规则待确认」。
- PC：最大内容宽度、2–4 列卡片；H5：2列或按可读性1列，触控目标≥44px；长标题2行截断。
- 证据：`module_live/pages/live/live_home.vue`、`module_live/apis.js`、`module_social/apis.js`。

### C-P03 主播热度榜

- 用途：当前仅验证榜单视觉；数据未接入。
- 结构：标题、日/周/月分段控件；排名、头像、主播名、分类、热度；前三名差异化但不使用误导性奢华效果。
- 必须设计：加载骨架、空榜、接口失败、更新时间、口径说明、并列名次/超长数字；这些是生产设计需求，但实现均标「待榜单 API 确认」。
- 禁止：把源码内 5 条静态昵称、倍率热度作为真实业务；擅自设计打赏榜、财富榜或点击跳转。
- 证据：`module_live/pages/live/live_rank.vue`。

### C-P04 个人中心

- 用途：用户资产、社交和创作者能力总入口。
- 结构：头像/昵称/手机号/签名/账号编号/主播身份徽标；钱包卡；礼物记录卡；主播才显示收益和主页管理；关注/粉丝；主播统计；社交入口；创作者入口；账号只读信息；退出。
- 角色差异：普通用户显示申请主播；审核中显示进度；驳回显示重新申请；审核通过显示认证主播、开播/收益/主页管理；身份查询失败不能误显示普通用户。
- 状态：账号资料全局刷新；钱包/社交/收益摘要各自加载/失败/禁用；不因一个模块失败清空整页。余额错误显示安全文案，不暴露内部错误。
- 操作：点击卡片进入对应页；未通过主播点「主播开播」转申请页并 Toast；退出二次确认。
- PC：2–3列仪表盘；H5：单列卡片并保持底部 Tab；资产数字防溢出。
- 证据：`module_live/pages/user/main_user.vue`。

### C-P05 直播间

- 用途：观看直播并进行轻互动和礼物消费。
- 层级：1)状态层；2)模糊封面背景；3)HLS画面；4)始终可操作的顶/底层。顶层含主播头像/昵称/在线人数/关注、最多3位在线会员、拉黑菜单、退出；底层含聊天占位、收藏、点赞、更多占位、礼物。
- 播放状态：进入中；缺 roomNo；房间加载失败；未开播/准备中/结束中/已结束/不可播放；播放器初始化/加载/缓冲；自动播放被阻止；手动播放；媒体失败；直播结束。每个失败态提供重试或退出，不能遮挡安全退出。
- 音频：自动播放可先静音；出现「继续静音/同意并开启声音」弹层；拒绝或失败仍能静音观看。
- Presence：显示会员+游客总在线；统计降级显示「在线人数同步中」而不是0；游客可观看但不能点赞；网络恢复自动重连；统计失败不能暂停合法播放。
- 社交：关注/收藏忙态；拉黑危险确认；游客触发互动进入登录；自己房间隐藏关注/拉黑且禁送礼。
- 礼物面板：分类、礼物图/珍稀标、余额、数量输入与1/10/99预设、总COIN、发送；目录空/错；余额不足、钱包停用、自送、场次结束、规则无效、频率限制；未知结果保留原请求并允许查询/安全重试。成功只展示本人确认动画。
- 明确占位：聊天输入框不可编辑；“更多”禁用；不得生成完整聊天/弹幕稿。
- 证据：`module_live/pages/live/live_room.vue`、`presence/controller.js`、`module_gift/components/*`。

### C-P06 主播公开主页

- 用途：游客/会员了解主播、进入直播和查看公开贡献/守护。
- 结构：照片轮播；头像、认证、主播号、等级、地区、语言、标签、简介、关注/粉丝；关系操作；直播卡；贡献榜；守护；分享。
- 相册：空相册；缩略图；左右滑动；全屏预览/计数/键盘方向键；图片独立加载失败重试。
- 贡献榜：日/月/总，首屏3人，展开20/页，上一/下一页，超过2000显示范围说明；金额/排名字符串展示。
- 守护：功能关闭、无守护、守护用户、方案与服务端明示权益。不能增加源码不存在的购买按钮。
- 关系：游客操作登录后返回本页；关注/取消/回关、共同关注、拉黑；拉黑确认后主页可能不可访问；本人显示「管理我的主页」。
- 分享：二维码、链接、复制、系统分享；失败降级；canonical URL 不含 token/query。
- 证据：`module_anchor_home/pages/anchor-home.vue`、`components/{photo-gallery,home-list,share-home}.vue`。

### C-P07 用户资料

- 用途：登录用户查看普通账号公开资料与关系。
- 结构：头像、昵称、签名、账号编号、关注/粉丝数；非本人显示关注、共同关注、拉黑；正在直播时显示入口。
- 状态：加载/失败重试；资料不存在或无权限；关系局部失败；本人态；图片失败占位；账号被拉黑。
- 导航：主播旧资料路由在守卫中直接重定向 C-P06；普通账号保留本页。
- 证据：`module_social/pages/social_profile.vue`、`routers/guards.js`。

### C-P08 社交与内容

- 用途：统一管理关系和观看记录。
- 变体：关注、粉丝、互关、看过、黑名单为可见 Tab；共同关注由资料页深链进入，页面标题随 section 变化但不在常驻 Tab。
- 列表：头像/昵称/账号、关系描述、直播红点；关注类显示关注/已关注/互关/回关/取消拉黑与拉黑；历史显示最近观看时间、进入直播、删除。
- 操作：卡片进账号资料；切 Tab 清列表和游标；下拉刷新、滚动分页；历史右上「清空」需确认。
- 状态：每个 Tab 独立空文案；加载/分页/错误；关系按钮单项忙态；操作成功后当前项更新或移除；失败保留。
- 证据：`module_social/pages/social_center.vue`。

### C-P09 账号设置

- 用途：更新公开资料与密码，查看不可编辑认证信息。
- 个人资料：昵称必填≤64、头像地址≤500、签名≤255、性别、生日≤今天、国家2字母、地区/城市≤32、语言≤16。显示头像预览和账号状态。
- 密码：旧密码、新密码、确认；每项8–72字节；新旧不同；确认一致；三项密码显隐独立。
- 只读：手机号、实名认证状态及提示“暂不支持客户端修改”。
- 状态：字段校验、保存中、成功Toast、失败保留输入；改密成功替换token；服务端未返回新token则提示重新登录并清会话。
- App：日期用系统选择器；敏感输入禁截图能力待原生确认；键盘 Next/Done 顺序明确。
- 证据：`module_live/pages/user/user_set.vue`、`stores/store_user.js`。

### C-P10 主播申请

- 用途：申请主播、查看审核与重新提交。
- 无记录表单：性别、出生日期、直播分类（必选）、主页封面URL、国家/地区/城市、语言、标签ID逗号格式、签名≤255。顶部解释审核流程。
- 状态卡：身份读取中/失败；审核中；已通过；未通过+拒绝原因；主播号、申请/审核时间；三步时间线。
- 操作：刷新身份、提交、驳回后重新申请/取消编辑；已通过进入开播页。提交时整表禁用并滚动首个错误。
- 事实限制：标签当前要求数字ID输入，不应美化成可搜索标签选择器，除非产品补充数据源。
- 证据：`module_live/pages/user/user_to_anchor.vue`。

### C-P11 主播开播台

- 用途：配置直播间并向 OBS 提供推流凭证。
- 顶部：直播间标题、房间号、未开播/准备中/直播中/结束中状态、同步状态。
- 资格卡：允许/拒绝、服务端原因、限制截止时间；拒绝时跳主播状态，生成Key禁用。
- 设置：标题≤128、分类必选、封面≤500、公告≤500、可见范围公开/关注者/私密；保存、恢复已关闭直播间、生成Key。
- 场次：场次号、流名、开始时间、在线、观看、点赞；无场次空态；准备/直播/结束状态。
- 恢复：刷新后检测原 pending prepare 显示「恢复Key」；有场次无凭证显示「推流密钥未保存在本机」并允许刷新Push URL；结果未知不新建场次。
- 凭证：默认遮罩 publishToken、幂等Key、Push URL、Stream Key；显示/隐藏/复制；明确等同直播密码；有效期；OBS三步指南。
- 结束：危险确认；成功清本地Key、刷新房间和历史；失败保留当前状态。活动场次每10秒仅前台轮询，静默失败由手动同步暴露。
- PC：设置与场次双列、凭证多列；H5：单列、长URL横向/换行不撑破。
- 证据：`module_live/pages/user/user_live.vue`、`module_live/apis.js`。

### C-P12 我的钱包

- 用途：只读展示 COIN 权威余额和流水。
- 余额：可用、冻结、钱包状态、版本、更新时间；停用醒目标记。金额分组但保持完整精度。
- 流水：业务类型、时间、变动额、变动前后、短流水号；业务类型人工充值/冲正/消费/退款/未知“余额变动”。游标加载更多。
- 状态：余额/流水分别加载、分别失败；有旧成功数据时错误以内联条展示而不清空；钱包停用；账务异常不可重试；503+Retry-After倒计时；无流水说明需后台审核入账。
- 交互：下拉/右上刷新；冷却内不重复请求；回前台超过30秒只刷新余额。
- 禁止：充值按钮、转账、任意扣退款、展示内部 businessNo。
- 证据：`module_wallet/pages/wallet_home.vue`、`domain.js`、`errors.js`。

### C-P13 礼物消费记录

- 用途：本人核对送礼及退款结果。
- 结构：待确认请求警示；筛选全部/已完成/部分退款/已全额退款；订单卡含礼物、件数、总额、退款、净消费、时间、客服订单号；加载更多。
- 操作：刷新、切筛选、复制订单号、查询/安全恢复待确认请求；成功恢复后刷新钱包。
- 状态：首载/空/错/更多失败；图标失败用🎁；429冷却；断网/超时/503显示「结果待确认」；客服类冲突保留 requestId 并引导联系支持。
- 禁止：客户端退款按钮、内部钱包/分成字段。
- 证据：`module_gift/pages/gift_history.vue`、`domain.js`、`errors.js`。

### C-P14 主播收益

- 用途：主播查看收益、管理收款账户、申请提现、跟踪人工出款。
- 主区：可提现余额、冻结、已付款、待抵扣/账本版本；待结算/累计结算；结算记录；错误与X-Request-ID；收款账户入口；人工出款说明；提现列表。
- 提现筛选：全部、审核中、待出款、驳回、已付款、已取消。`approved` 必须写「审核通过·待出款」，不能写到账。
- 申请弹层：币种（多余额时）、金额、全部、active同币种脱敏账户、可用余额、冻结说明；确认框锁定金额+账户；提交成功说明已冻结等待审核。
- 收款账户：银行卡/支付宝/微信OpenID；完整字段为密码型；绑定≠实名认证/渠道认证；银行卡当前可人工出款，另两类无渠道；默认/停用；停用不可恢复；100上限。
- 恢复：未确认请求显示金额和短requestId；查询结果/安全重试；旧版无payee仅查询；明确49006且≥30s后才允许确认清除。
- 详情：金额、状态、申请/审核时间、收款方式/版本/脱敏号、提现单号、请求号；加载期间不可闪现旧单。
- 自动刷新：可见且有审核中/待出款时最多30s查询；隐藏/离页/断网停止；实时事件只能触发HTTP重查。
- 证据：`module_earning/pages/earning_home.vue`、`components/{settlement-list,payee-manager}.vue`、`domain.js`。

### C-P15 主播主页管理

- 用途：主播管理公开相册和介绍。
- 相册卡：已用/上限；照片缩略、审核中/已通过/未通过/已下架、拒绝原因、当前首图；设首图/前移/后移/删除；上传。
- 文件：JPG/PNG/WebP，1字节–8MB，最多20张；满额禁用。上传后不直接视为公开，等待审核。
- 结果未知：警示说明保留同一 requestId/version/file/photoNos；「重试上次操作」；操作期间其他写按钮禁用。
- 冲突：版本冲突刷新最新相册并提示重新操作；明确拒绝清 pending；未知错误保留 pending。
- 公开介绍：签名≤255实时计数、内容分类、版本保存；冲突/失败；成功消息。
- 预览：私有大图弹层；观众视角跳C-P06。关闭/换账号必须释放Blob URL。
- 证据：`module_anchor_home/pages/anchor-home-manage.vue`、`domain.js`。

### C-P16~19 与 C-D01~04

- C-P16 通用播放器、C-P17 电影、C-P18 关于和四个 C-D 路由均不属于已完成商业页面。AI 生成平台仅为 C-P19 404 生成正式稿。
- C-P18 的正式关于页可在产品确认品牌、版本、协议、隐私、客服、许可证后补设计；现阶段标待确认。
- 所有调试路由的生产需求是「不可被普通用户发现/访问」而不是重新美化。
