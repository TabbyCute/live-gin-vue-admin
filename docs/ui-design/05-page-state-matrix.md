# 页面和业务状态覆盖矩阵

## 1. 全局状态合同

| 状态 | 触发条件 | 页面变化/文案 | 可用操作 | 恢复方式 | 设计稿要求 |
| --- | --- | --- | --- | --- | --- |
| 默认 | 路由与数据就绪 | 展示最后一次权威数据 | 页面正常操作 | 无 | 每页基准稿 |
| 首屏加载 | 首次请求、无旧数据 | 骨架/加载动画；避免闪空态 | 返回/取消导航 | 请求完成 | 骨架形状接近最终内容 |
| 局部刷新 | 有旧数据重新请求 | 保留旧数据，刷新按钮转圈 | 仍可读，写操作按风险禁用 | 成功替换/失败保留 | 不用全屏遮罩 |
| 无数据 | 请求成功且 list=[] | 具体业务空文案 | 主要下一步（若真实存在） | 刷新/产生数据 | 禁止通用“暂无数据”替代业务说明 |
| 加载失败 | HTTP/业务错误且结果确定 | 安全文案；可带有效requestId | 重试/返回/客服 | 用户重试 | 页面内错误优先，Toast补充 |
| 网络异常 | Fetch TypeError/status=0 | “网络连接失败，请检查网络后重试” | 保留输入/旧数据；重试 | online事件或手动 | 离线条+局部错误，不伪装服务端失败 |
| 请求超时 | Abort timeout | “请求超时，请稍后重试” | 读请求可重试；写请求先查结果 | 同业务恢复策略 | 金融/幂等写入不得显示普通失败 |
| 服务端异常 | HTTP 5xx | “服务暂不可用” | 退避、重试 | 恢复后重读 | 不展示堆栈/数据库信息 |
| 容量/限流 | 429/503+Retry-After | 倒计时或“操作频繁” | 冷却期禁用 | 到期手动重试 | 明确剩余时间；不无限自动重试 |
| 未登录 | auth路由或互动缺token | 登录引导 | 去登录/取消 | 登录后安全返回原页 | 保留上下文，不弹多层重复确认 |
| 登录过期 | 401且请求token仍为当前token | 清敏感状态，跳登录；“登录状态已失效” | 重新登录 | 登录成功 | 旧账号迟到401不影响新账号 |
| 会话验证失败 | 有token但user/info网络失败 | “暂时无法验证登录状态” | 重新登录或重试 | 再次恢复 | 与明确过期区分 |
| 无权限 | 路由role/permission失败 | 返回首页 `forbidden=1`；主播未通过转申请页 | 返回/申请 | 权限变化后刷新 | 独立403页当前不存在，稿件按现有跳转 |
| 账号受限 | account status/业务码 | 状态标签+安全原因 | 查看状态/联系客服 | 服务端解除后刷新 | 不能提供绕过操作 |
| 数据格式异常 | 客户端严格DTO校验失败 | “数据格式异常，请稍后重试” | 重试/反馈requestId | 服务升级修复 | 不展示部分不可信资金数据 |
| 页面重进 | keepAlive或重新路由 | 主Tab保留滚动/状态；非缓存页重读 | 刷新 | 自动 | 标注哪些保留、哪些重置 |
| 账号切换 | token/accountNo变化 | 立即清旧账号余额、关系、敏感表单与迟到响应 | 新账号重新加载 | 自动 | 不得出现旧账号闪屏 |

## 2. 组件交互状态

| 组件 | 必须 variants | 行为 |
| --- | --- | --- |
| 主按钮 | default/hover(PC)/pressed/focus/disabled/loading/success/danger | loading 保持宽度；危险操作需确认；触控≥44px |
| 文本按钮 | default/hover/focus/disabled | 不仅靠颜色表达禁用/选中 |
| 输入框 | empty/filled/focus/valid/error/disabled/read-only/password-visible | 错误说明与字段关联；键盘类型正确；金额不自动格式化破坏光标 |
| Tab | default/active/hover/focus/disabled/overflow | URL section 与选中态同步；可横向滚动；焦点可见 |
| 卡片 | normal/hover(PC)/pressed/loading/selected/error | 点击区完整；卡片内按钮阻止冒泡 |
| 图片 | loading/success/broken/blocked/private | 头像用首字占位；封面渐变；私有Blob离开释放 |
| 列表 | initial/loading/pull-refresh/load-more/nomore/nodata/error | 已有列表时更多失败不清空 |
| Popup/Modal | opening/open/confirming/closing/error | 焦点圈、Esc/返回、遮罩、滚动锁、safe area |
| Toast | success/info/error | 只作短反馈；关键错误必须留在页面 |
| 状态标签 | neutral/info/success/warning/danger/disabled | 图标/文案+颜色，满足色盲可识别 |

## 4. 关键业务状态详表

### 4.1 身份与主播

| 状态 | 触发 | UI/文案 | 操作/恢复 |
| --- | --- | --- | --- |
| 普通用户 | 无主播记录 | “普通用户/申请成为主播” | 进入C-P10 |
| 审核中 | applyStatus=1 | “申请审核中”，时间线停在平台审核 | 刷新；不可重复提交 |
| 已通过 | applyStatus=2 | “认证主播”，显示主播号/状态 | 开播、收益、主页管理 |
| 未通过 | applyStatus=3 | “申请未通过”+rejectReason | 重新申请；取消编辑回状态卡 |
| 主播停用/封禁/注销 | anchor.status=0/2/3 | 危险标签，资格卡说明 | 禁止生成Key；查看状态/联系平台 |
| 无直播权限 | livePermission!=1 | “直播权限未开通” | 禁止开播 |
| 临时限制 | qualification allow=false+banUntil | 原因+截止时间 | 截止后主动刷新 |

### 4.2 直播房间与播放器

| 状态 | 触发 | UI | 可用操作 |
| --- | --- | --- | --- |
| 未开播 | liveStatus=0/无有效session | 封面+“当前暂无可播放画面” | 退出、看主播资料/关注（若数据可用） |
| 准备中 | liveStatus=1 | “直播准备中” | 等待/重试详情 |
| 直播中 | liveStatus=2+地址 | 播放画面+完整操作层 | 所有符合权限互动 |
| 结束中 | liveStatus=3 | “直播正在结束” | 退出，禁止送礼 |
| 自动播放受阻 | 浏览器play reject | “直播已准备好/点击播放” | 手动播放 |
| 音频需同意 | 自动静音后可启声 | 声音授权弹层 | 继续静音/开启声音 |
| presence降级 | 心跳/Redis/网络失败 | 在线显示“同步中/—”；播放不停止 | 自动退避、网络恢复 |
| 场次关闭 | heartbeat closed=true | “直播已结束” | 退出/回首页 |

| 状态 | 触发 | UI/文案 | 操作/恢复 |
| --- | --- | --- | --- |

| 余额不足 | 47010 | “可用 COIN 余额不足” | 去钱包只读页；充值能力不存在 |

### 4.4 收益、收款与提现

| 状态 | 触发 | UI/文案 | 操作/恢复 |
| --- | --- | --- | --- |
| 无可提现余额 | available=0 | 提现按钮禁用，显示余额 | 等待结算 |
| 有欠额 | debt>0 | 红/警告“待抵扣” | 不承诺驳回后全额返还 |
| 无收款账户 | active同币种为空 | 申请弹层提示先绑定 | 打开账户管理 |
| 账户停用 | status=disabled | 灰色“已停用”，不可选 | 无恢复；可新建其他账户 |
| 绑定结果未知 | 超时/49103 | 保留原敏感表单和requestId，提示原资料重试或关闭后查列表 | 不自动换键 |
| 提现审核中 | pending_review | 黄色“审核中”，金额冻结 | 查看详情/等待 |
| 审核通过 | approved | 黄色“审核通过·待出款” | 等待人工出款；绝不写已到账 |
| 驳回 | rejected | 红色“已驳回” | 刷新余额；释放金额可能先抵欠额 |
| 已付款 | paid | 绿色“人工复核已付款” | 查看详情 |
| 已取消 | cancelled | 灰色“已取消·冻结已释放” | 查看详情 |
| 提现结果未知 | 断网/5xx/49003/49004 | 顶部持久警示+原金额/requestId | 查询；原四参数安全重试 |
| 旧请求未创建 | 缺payee+49006+≥30s | “处理旧版待确认请求” | 二次确认清本地记录；不修改服务端已存在单 |
| 对账/事实异常 | 49009/11/12 | “提现已安全暂停/待核验” | 联系平台；禁止绕过 |

### 4.5 主播主页相册

| 状态 | 触发 | UI | 操作/恢复 |
| --- | --- | --- | --- |
